This post exists to show what you can do inside a thought. Copy any block
below into a new `.mdx` file and edit it.

<Section title="Headings, emphasis, and size">
  Normal Markdown works everywhere: **bold**, *italic*, `inline code`,
  [links](https://example.com), and lists.

  <Sized as="h3" size="lg" align="center" serif>A large centered heading</Sized>

  <Sized size="sm" color="mute" align="center">fine print, smaller and muted</Sized>
</Section>

<Divider variant="dots" space="md" />

<Section title="Blockquotes, pull-quotes, and callouts">
  A normal Markdown blockquote:

  > Boring infrastructure is underrated.

  A larger editorial pull-quote:

  <Pullquote>The fastest code is the code you never wrote.</Pullquote>

  Asides for notes, warnings, and tips:

  <Callout kind="note">
    This is a side note. It renders as a muted box.
  </Callout>

  <Callout kind="warn" title="Don't">
    Never run <code>rm -rf /</code> in production. Probably.
  </Callout>

  <Callout kind="tip">
    Store UTC. Render in the user's locale. This is advice, not a suggestion.
  </Callout>
</Section>

<Divider variant="dotted" space="md" />

<Section title="Code blocks">
  Fenced code blocks work as usual:

  ```python
  def idempotent(handler):
      def wrapped(event):
          if already_processed(event.id):
              return "ok"
          handler(event)
          mark_processed(event.id)
          return "ok"
      return wrapped
  ```
</Section>

<Section title="Animated canvas">
  A tiny inline canvas animation. Paused when offscreen, and rendered as a
  single static frame when the user prefers reduced motion.

  <Canvas
    id="sine-demo"
    width={600}
    height={120}
    caption="Figure 2: a sine wave. Animation only runs while in view."
    draw={`(ctx, t, w, h) => {
      ctx.clearRect(0, 0, w, h);
      ctx.strokeStyle = "#1a1714";
      ctx.lineWidth = 2;
      ctx.beginPath();
      for (let x = 0; x < w; x++) {
        const y = h / 2 + Math.sin((x + t) * 0.04) * 32;
        x === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
      }
      ctx.stroke();
    }`}
  />
</Section>

<Section title="GIFs">
  GIFs are just images. Drop a `.gif` in `public/thoughts/<slug>/` and use
  `<Figure>` or plain Markdown:

  ```mdx
  ![alt text](/thoughts/my-post/animation.gif)
  ```
</Section>

<Section title="Thumbnails (optional)">
  A thought can carry a thumbnail that shows up on the thoughts index and
  homepage latest list. Add `thumbnail` (and optional `thumbnailAlt`) to the
  frontmatter:

  ```yaml
  ---
  title: "My thought"
  date: 2026-08-13
  tags: [software]
  thumbnail: "/thoughts/my-thought/cover.png"
  thumbnailAlt: "A diagram of the system described below."
  ---
  ```

  Drop the image under `public/thoughts/<slug>/`. If `thumbnail` is absent, the
  list renders as a plain row. This post has one set, so the index shows it.
</Section>

<Section title="That's it">
  If you need richer state or interaction than the canvas helper allows, write
  a Svelte component in `src/components/` and import it here with `client:visible`:

  ```mdx
  import InteractiveTimeline from "../../components/InteractiveTimeline.svelte";

  <InteractiveTimeline client:visible />
  ```
</Section>

<Section title="Math and equations">
  Inline math like <Math>E = mc<sup>2</sup></Math> fits in the sentence.
  Block equations center on their own line:

  <Math block label="eq:energy">
    E = m c<sup>2</sup>
  </Math>

  Labeled equations can be referenced by their label, rendered as `(energy)`
  next to the equation. Superscripts use `<sup>`, subscripts use `<sub>`:

  <Math block label="eq:newton">
    F = m a = G m<sub>1</sub> m<sub>2</sub> / r<sup>2</sup>
  </Math>
</Section>
